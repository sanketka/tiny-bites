# Baby Breakfast Bot

Sends a daily Telegram message at 8 PM PT with a breakfast recipe for Sanket's 15-month-old. Recipes are generated by Claude Haiku based on what's in the pantry. Scheduled via GitHub Actions.

## What Each File Does

- `send_breakfast.py` — main script: loads pantry + config, calls Claude, sends Telegram message, logs recipe
- `pantry.txt` — source of truth for what's stocked at home. Edit this when groceries change, push to update.
- `config.txt` — controls cuisine mode: `western`, `indian`, or `mixed`. Currently set to `western` for the first week, then switch to `mixed`.
- `recipe_log.json` — auto-updated by GitHub Actions after each run. Tracks last 7 recipes to avoid repeats. Do not edit manually.
- `worker/index.js` — Cloudflare Worker for interactive Telegram commands (/new, /indian, /western). Not yet deployed — see backlog.
- `worker/wrangler.toml` — Cloudflare Worker config
- `backlog.md` — improvements log. Add to this when new ideas come up.
- `.github/workflows/daily_breakfast.yml` — cron job, fires at 03:00 UTC (8 PM PDT). Update to 04:00 UTC in November when clocks fall back.

## Nutrition Priorities

Protein first, then fiber, then carbs. Recipes are tailored for a 15-month-old: soft textures, no honey, no choking hazards, low sodium.

## How to Test

Trigger manually from GitHub Actions tab, or via CLI:
```bash
gh workflow run daily_breakfast.yml
```

## Key Gotchas

- `recipe_log.json` is committed back to the repo by the GitHub Action after each run — always `git pull --rebase` before pushing to avoid conflicts.
- DST: cron is set to `03:00 UTC` (PDT). Change to `04:00 UTC` each November when clocks fall back, revert in March.
- Pantry and config are read fresh at runtime — no code changes needed for routine updates.
- Model: Claude Haiku 4.5. Sufficient for this use case. Upgrade to Sonnet only if output quality is consistently poor.
